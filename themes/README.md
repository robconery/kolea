# 🎨 Themes

The built-in themes for the public site, compiled into the Worker by
`bun run build:theme`:

| Theme | The idea |
|---|---|
| 📖 `folio/` (default) | A printed book: warm paper, one vermilion ink, a table of contents. |
| 📰 `signal/` | A magazine: a colour per topic, an asymmetric spread, big motion. |
| 🌆 `nightdrive/` | After dark: neon blues and violets, an SVG sunset and grid floor. |

**How templates work, how to change a theme, and how to make your own (with Claude):
[`docs/templates.md`](../docs/templates.md).**
